# Paciência

Klondike, Spider, FreeCell, Pyramid e TriPeaks em um só app, com visual de vidro líquido.
Funciona offline e pode ser instalado no celular ou no computador.

Site: `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Publicar no GitHub Pages
1. Crie um repositório público e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages**, em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
3. Aguarde cerca de 1 minuto e abra o endereço mostrado na página.

## Atualizar o site
Depois de mudar o `index.html`, troque `VERSION` em `sw.js` (por exemplo, `paciencia-v2`) para os aparelhos receberem a versão nova.
